## 核心功能模組

1. **XLK 科技股 & SOXX 半導體（25–28 年歷史全景與回測）**
   - **固定跌幅門檻**：`≤ -5.0%`、`≤ -7.5%`、`≤ -10.0%`（未四捨五入精確浮點判定）
   - **統計波動門檻（無前視偏差 252 日滾動口徑）**：`≤ 平均日跌幅`、`≤ -1σ`、`≤ -2σ (兩倍標準差)`，嚴格採 `[max(1, i-252)..i-1]`（首年採 `min_periods=60` Expanding Window），並於專屬 `-2σ` 專區與總覽表同步對照全歷史靜態參考值。
   - **量化審計口徑**：固定滿 20 日樣本池平均走勢（無假性跳空）、10 日冷卻獨立訊號 Welch t 檢定、200MA 多空分層（含上市初期 `<200日`）、MAE/MFE 邊界截斷、高頻事件 ECharts 大量渲染與明細帳分頁。
2. **XLK vs SOXX 跨標的六門檻對照**
   - 支援六大門檻即時切換，並列比較 T+0～T+20 反彈路徑、1～12 月發生季節性與盤中回撤風險。
3. **愛大（愛榭克 Izaax）2021–2026 課程簡報實證回測（第 4 分頁）**
   - 13 場公開簡報與講座筆記時間軸對帳（跨時區當地交易日對齊、未滿期標「未滿期」零截斷、分離真實 Peak-to-Trough MDD 與 MAE）。
   - 六大推論類別實證勝率計分卡（對照同期無腦 Buy & Hold 12M 基準率）。
   - 景氣週期事前切分疊加 XLK / SOXX 暴跌回測 vs 200MA 客觀濾網對決。
4. **機構量化終端介面**
   - 預設消光曜石黑量化終端主題，頂部提供一鍵切換「終端深色 / 研報淺色」與主題連動 PNG 圖卡匯出。
